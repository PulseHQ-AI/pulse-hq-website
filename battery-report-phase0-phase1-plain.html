## PHASE 1 — DELIMITER EXTRACTION (D01–D14)

Method: isolated fixture tests/phase1-delimiter.js exercising
pbParseMarker (the production parser, unmodified) — 22 checks,
0 failures. Parse-level classification: EXECUTED + VERIFIED
(independently inspectable: fixture source + recorded output).
Live corroboration is classified separately per test.

D01 marker at beginning — PASS, both directions (to alex / to remmy).
  Live: VERIFIED both directions (standing operation).
D02 marker in middle — PASS: body = payload only; preamble excluded.
  Live: VERIFIED both directions (Alex's buried-marker tests
  pb-mw8q512q-1-e0si, pb-mw8qb2tv-2-fze4; Remmy's preamble letter).
D03 marker near end — PASS: only the remainder routes ("short tail").
D04 no marker — PASS: null, no routing.
D05 incorrect spelling — PASS: TO-ALEXX → null; missing hyphen → null.
D06 altered characters — PASS: wrong bracket → null; zero-width char
  inside marker → null; lowercased marker → null (case-sensitive).
D07 multiple markers — PASS: first valid delimiter controls; a second
  marker (either direction) rides in the body as payload.
D08 PROBE, marker inside fenced code — ACTUAL BEHAVIOUR: ROUTES.
  The parser has no fence awareness: a standalone marker line inside
  a ``` fence delimits; body = everything beneath it (including the
  closing fence and following text).
D09 PROBE, marker inside quoted text — ACTUAL BEHAVIOUR, two shapes:
  (a) marker prefixed "> " on its line: does NOT route (the line is
      not standalone).
  (b) marker alone on its own line within a quotation: ROUTES
      (body = text beneath it). Matches letterbox scenario C2.
D10 empty content after marker — PASS: null in both forms (nothing
  beneath; only whitespace beneath). No invented payload.
D11 unicode + emoji — PASS: payload preserved exactly (🌷, accents,
  em dash, surrogate-pair emoji).
D12 multiple blank lines — PASS: internal blank lines preserved;
  preamble blank lines excluded with the preamble.
D13 long preamble — PASS: 200-line preamble excluded completely;
  body exactly the payload.
D14 long payload (parse level) — PASS: 20,000-char payload extracted
  complete, SHA-256 of extracted body identical to source payload.
  (Parse level only; live carriage at size is Phase 2's ladder.)

**Delimiter, defined precisely (from D08/D09):** the first line of
the message's extracted text whose trimmed content equals a reserved
marker exactly. The test is context-blind by design — no fence
awareness, no quote awareness. Live-surface behaviour for the D08/D09
shapes additionally depends on whether a surface's extraction
preserves fence/quote lines as raw text lines; that live check has
NOT been run and is not claimed.
